# docterminal
##### July 2026 - Present

</div>

&nbsp;

## Overview
Terminal personal workspace system demonstrating object-oriented design patterns and secure authentication that handles local user state, task management, and deadline alerts

&nbsp;

## Features

**Authentication**
- Account registration, secure hashed login, security questions, and automatic account lockout after 3 consecutive failed attempts

**Task Management**
- CRUD operations (Create, Read, Update, Delete) for workspace tasks and assignments

**Automated Urgency System**
- Deadline engine that computes due dates, automatically flagging tasks due within 3 days as urgent

**State Persistence**
- Local per-user JSON storage ensuring workspace state, settings, and task history are saved and restored seamlessly across sessions
